Great Zille Solution - Early Beta (v0.1-beta)
=============================================

REQUIREMENTS:
- Suzerain (Steam)
- MelonLoader (0.6.x / 0.7.x) installed in your Suzerain game directory

INSTALLATION:
1. Install MelonLoader into your Suzerain folder if you haven't already.
2. Extract the "Mods" folder from this archive directly into your Suzerain game directory
   (e.g. C:\Program Files (x86)\Steam\steamapps\common\Suzerain\).
   You should end up with:
   - <Suzerain>\Mods\GreatZilleSolution.dll
   - <Suzerain>\Mods\GreatZilleAssets\...
3. Launch the game!
