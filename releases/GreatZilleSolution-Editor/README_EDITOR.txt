Great Zille Solution - Standalone Editor & Decompiler
=====================================================

WYMAGANIA:
- Python 3.9+
- UnityPy (zainstaluj przez: pip install -r requirements.txt)

URUCHOMIENIE:
1. Zainstaluj zależności: pip install -r requirements.txt
2. Uruchom launch_editor.bat (lub: python server.py)
3. W przeglądarce kliknij "⚙️ SUZERAIN & DEKOMPILATOR", wklej ścieżkę do folderu gry Suzerain
   (np. C:\Program Files (x86)\Steam\steamapps\common\Suzerain), zapisz i kliknij "Dekompiluj dane z gry".
   Możesz też uruchomić dekompilator z linii poleceń:
   python decompile.py --game-dir "C:\Sciezka\Do\Suzerain"
